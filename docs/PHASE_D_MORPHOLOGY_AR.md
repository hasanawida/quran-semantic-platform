# المرحلة D — الصرف متعدد المصادر

## المبدأ

**الكلمة ملك النص، والتحليل ملك مصدره.**

النص القرآني مرجع لا يُشتق من التحليل. التحليل الصرفي منقول عن مصادر
خارجية موثقة، منسوب إليها حرفيًا، ومتعدد بطبيعته: حين تختلف المصادر
يُعرض الخلاف ولا يُحسم آليًا.

## خط المعالجة

```
نص الإصدار الموثق ──ترميز──▶ tokens
                                │
مصدر صرفي (بصمة + رخصة) ──استيراد──▶ morphological_analyses
                                │
                  مقارنة المصادر كلمةً كلمة
                                │
          ┌─────────────────────┴──────────────────┐
     اتفاق / مصدر واحد                         اختلاف
          │                                        │
          ▼                                        ▼
   root_occurrences ◀──── قرار مراجعة معتمد ──── يبقى معلّقًا
```

كل خطوة حتمية وقابلة للإعادة، وتُسجَّل في سجل التدقيق بفاعلها.

## الجداول

| الجدول | المعنى |
| --- | --- |
| `tokens` | ترميز المنصة لكلمات كل آية، بمواضع الحروف في نص الآية |
| `morphology_sources` | مصادر التحليل ببصمة الملف ورخصته وحالته |
| `morphological_analyses` | مقطع صرفي من مصدر: الصيغة والوسم والسمات حرفيًا + جذر وأصل |
| `token_root_decisions` | قرار بشري معلَّل في جذر كلمة، باعتماد مراجع ثانٍ |
| `token_root_decision_roots` | جذور القرار (كلمة قد تحمل أكثر من جذر) |
| `golden_root_cases` | مواضع مرجعية تكشف انحراف خط الاشتقاق |

## سياسة الترميز

الكلمة ما حمل حرفًا عربيًا. علامات الوقف المستقلة (ۖ ۗ ۘ) لا تأخذ رقمًا،
وهو ما يوافق ترقيم المدونة القرآنية فتصح المحاذاة. التقسيم على الفراغ
وحده: لا يُحذف من النص شيء، وتُحفظ مواضع الحروف (`char_start`/`char_end`)
فيبقى التمييز مربوطًا بالنص الموثق لا بنسخة معالجة منه.

## فصل البسملة (تصحيح جوهري)

ملف تنزيل المستعمل يدمج البسملة داخل نص الآية الأولى من كل سورة عدا
الفاتحة (هي فيها آية مستقلة) وبراءة (لا بسملة فيها). أثر ذلك:

- تُعرض «2:1» نصًّا «بِسْمِ ٱللَّهِ… الٓمٓ» وهو مخالف للعد الكوفي المعلن.
- ينزاح ترقيم الكلمات أربعًا في أول كل سورة فتفشل محاذاة التحليل.

الفصل **نقل حرفي لا تعديل**: تُطابق أول أربع كلمات على صورة البسملة
المطبَّعة (لأن الملف يكتبها بصورتين: `بِسْمِ` و`بِّسْمِ` في السورتين 95 و97)،
ثم تُقتطع **بالمواضع** فتُحفظ بايتات كل سورة كما وردت، وتُخزَّن في
`surahs.basmala_text`.

**الشاهد على صحة الفصل:** نسبة تطابق عدّ الكلمات مع مدونة ليدز — وهي مصدر
مستقل تمامًا — قفزت من **98.14% إلى 99.94%**.

الأربع الباقية اختلاف اصطلاح حقيقي في حدود الكلمة لا خطأ:

| الموضع | النص | المدونة |
| --- | --- | --- |
| 2:181، 8:6، 13:37 | `بَعْدَ` + `مَا` كلمتان | `baEodamaA` كلمة واحدة |
| 37:130 | `إِلْ` + `يَاسِينَ` كلمتان | `<ilo yaAsiyna` كلمة واحدة |

في هذه الآيات يُحفظ التحليل ويُنسب، ولا يُربط بكلمة (`token_id` فارغ)،
ويُمنع التمييز (`is_highlight_safe = false`). الادعاء الأضعف هو الأصدق.

## اشتقاق المواضع

لكل (آية، كلمة) تُجمع مجموعة جذور كل مصدر على حدة، ثم:

| الحالة | النتيجة | `derivation` |
| --- | --- | --- |
| قرار مراجعة معتمد | جذور القرار | `human_decision` |
| اتفاق مصدرين فأكثر | المجموعة المتفق عليها | `source_agreement` |
| مصدر واحد فقط | مجموعته | `single_source` |
| اختلاف بلا قرار | **لا موضع** — يبقى في قائمة التعارضات | — |

المصدر المعطَّل (`is_enabled = false`) يبقى محفوظًا للتتبع ويُستبعد من
الاشتقاق.

## التحقق من صحة الخط

أُعيد بناء المواضع كاملة من التحليلات ثم قورنت بمواضع البذر المباشر:

```
مواضع البذر:    49,968   آمنة للتمييز 49,941
المواضع المشتقة: 49,968   آمنة للتمييز 49,941
تطابق تام:      نعم (0 فرق في الاتجاهين)
```

ومعه 12 موضعًا مرجعيًا (`data/golden_roots.json`) تغطي: السوابق
واللواحق، صور الهمزة الثلاث في جذر واحد، الكلمة الوحيدة بجذرين
(`يٰبْنَؤُمَّ` 20:94)، «لا جذر» مقابل «لا تحليل»، مرساتَي فصل البسملة،
وآية غير محاذية.

## المصدر المستورد

| | |
| --- | --- |
| الرمز | `qac-0.4` |
| المصدر | Quranic Arabic Corpus — جامعة ليدز |
| الرابط | <https://corpus.quran.com> |
| الرخصة | GNU GPL — الإسناد والرابط وعدم تعديل الملف |
| المقاطع | 128,219 |
| الكلمات | 77,429 |
| الجذور | 1,642 |
| الأصول | 4,817 |

الصيغة والسمات تُحفظ **حرفيًا كما وردت** (بترميز بكوولتر) احترامًا لشرط
الرخصة، والحقول المشتقة (القسم، الأصل، الجذر) للفهرسة والعرض.

> المصدر واحد اليوم، والبنية مهيأة لأكثر. لا يُدَّعى اتفاق مصادر ولا
> تُلفَّق مصادر: كل موضع اليوم حالته `single_source` صراحةً.

## التشغيل

```bash
# بناء حزمة الصرف من الملف الخام (مرة واحدة، حتمية)
python scripts/import-quran/build_morphology_bundle.py

# تهيئة قاعدة التطوير كاملة: مخطط + بذر + ترميز + استيراد + اشتقاق + فحص
cd apps/api && .venv/Scripts/python.exe -m app.cli bootstrap
```

الاستيراد ~70 ثانية (128 ألف مقطع في SQLite)، لذا لا يجري تلقائيًا عند
الإقلاع: هو عملية إدارية موثقة بفاعل معروف.
