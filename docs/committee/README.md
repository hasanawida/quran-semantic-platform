# لجنة الخبراء — الحال: **غير مشكَّلة**

> §18: «لا تعتمد المنصة نفسها بنفسها.»
> §20: ١٠/١٠ يشترط **موافقة كل أعضاء اللجنة ضمن اختصاصاتهم**.

## الحال اليوم بصراحة

**صفرٌ من ستة عشر اختصاصًا مشغول.** ولا يُنشأ هنا ملفُّ خبيرٍ وهميّ ولا
«وكيل» يحمل اسم اختصاص — لأن §4٫16 تمنع البيانات الوهمية، ولأن دورًا في
النظام باسم «مراجع شرعي» **ليس مراجعةً شرعية**.

فما دامت اللجنة غير مشكَّلة، **لا اعتماد**. وتقف كل نتيجةٍ عند «متحقق
آليًّا من المصادر» ولا تتعدّاها.

> **وحذفٌ مقصود:** §18 تجيز عند تعذّر تعدد الوكلاء «مراجعات مستقلة متتابعة
> مع فصل السياق». **ولا يُعمل بها هنا.** مراجعتان متتابعتان من وكيلٍ واحد
> ليستا مراجعتين مستقلتين: فصلُ السياق يمنع التذكّر ولا يمنع تكرار الخطأ،
> لأن مصدر الخطأ النموذجُ لا ذاكرتُه. (وهذا الخطر R-17.)
