## ما لا تغطيه ١٨٤

مقيسٌ مقابل §39 «الاختبارات الحرجة»:

| المجموعة | مغطّى؟ |
|---|---|
| سلامة النص (حرف، حركة، علامة وقف، بسملة، تبديل آيتين) | **نعم** — وهي أقوى ما في المنصة |
| إعادة بناء الملف الخام والحصول على البصمة نفسها | نعم، لكن مع التخطّي أعلاه |
| المصادر: مصدر غير معتمد، طبعة بلا بصمة، ترخيص غامض | **لا** |
| تعديل ملف معتمد، OCR غير مراجع | **لا** — لا OCR ولا ملفات أصلية أصلًا |
| المعرفة: ادعاء بلا دليل | نعم جزئيًا (`test_scholarship.py`) |
| قول بلا قائل، اقتباس بلا صفحة | **لا** — لا جدول صفحات |
| دمج أقوال، إخفاء خلاف | **لا** |
| الحديث كله | **لا** — لا طبقة حديث |
| الذكاء الاصطناعي كله | **لا** — لا طبقة ذكاء |
| الأمن: أسرار في المستودع، حقن، صلاحيات زائدة | جزئي |
| الواجهة: روابط 404 | **نعم** — `test_static_links.py` (٤ اختبارات) |
| الواجهة: أنواع محتوى غير مميَّزة | **لا** |
