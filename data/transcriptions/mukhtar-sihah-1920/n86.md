الأخفش : ( تَبِعه ) و ( أَتْبعه ) بمعنًى مثل رَدِفه وأَرْدفه . ومنه قوله تعالى : « إلا مَن خَطِفَ الخَطْفَةَ فَأَتْبَعَـه شِهَابٌ ثَاقِبٌ » و ( التَّبَعُ ) يكون واحدا وجَمْعـا قال الله تعالى : « إنَّا كُنَّا لكم تَبَعًا » وجَمْعُه ( أَتْبَاع ) و ( تَابَعَه ) على كذا ( مُتَابَعَةً ) و ( تِبَاعًا ) بالكسر و ( التِّبَاع ) أيضا الوَلَاء . و ( تَابَـع ) الرجلُ عَمَـلَه أى أَحْكَمه وأَتْقَنَـه . وفى حديث أبى وَاقِدٍ اللَّيْثِىّ « تَابَعْنَا الأَعْمالَ فلم نَجِـد شيئًا أَبْلَغَ فى طَلَبِ الآخِرة من الزُّهْـدِ فى الدُّنيـا » أى أَحْكَمْناها وعَرَفْنـاها . و ( تَتَبَّع ) الشىءَ تَطَلَّبَه مُتَتَبِّعا له وكذا ( تَتبَّعه ) بتشديد الباء أيضا . و ( التِّبَاعة ) بالكسر مثل التَّبِعة و ( التَّبِعة ) ما ٱتُّبِـع به ذَكَره الفارابِىّ فى الديوان و ( التَّبِيــع ) التـابع . وقوله تعالى : « ثُمَّ لا تَجِدُوا لكم علَينا به تَبِيعًا » قال الفَرَّاء أى ثائرًا ولا طالِبا وهو بمعنى تابع . والتَّبِيعُ ولَدُ البقرة فى أَوّل سنَة والأُنْثَى تبيعة والجَمْع ( تِبَاع ) بالكسر و ( تَبَائع ) مثل أَفِيل وأَفَائل . وقولهم مَعَه ( تابِعة ) أى من الجِنّ

* ت ب ل
( التَّابَِل ) بفتح الباء وكسرها واحد ( تَوَابِل ) القِدر

* ت ب ن
( التِّبْـن ) معروف الواحدة تِبْنة و ( التَّبْن ) بالفتح مصدر ( تَبَنَ ) الدَّابةَ أى عَلَفَها تِبْنا وبابه ضرب . و ( تَبَّن تَتْبِينا ) أَدَقَّ النَّظَر وهو فى حديث سالم بن عبد الله رضى الله عنهما . و ( التَّبَّان ) الذى يبيع التِّبْنَ وإن جعلته فَعْلانَ من التَّبّ لم تصرفه . و ( التُّبَّان ) بالضم والتشديد سَرَاوِيلُ صغير مقـدار شِبْرٍ يَسْـــتر العَوْرة المُغَلَّظة وقد يكون للمَلَّاحين

* ت ج أ
(١) ( تَجَأْجَأَ ) أى نَكَص

* ت ج ر
( تَجَـر ) من باب نصر وكتب وكذلك ( ٱتَّجر ٱتِّجارا ) وجَمْع ( التَّاجِر تَجْرٌ ) كصاحب وصَحْب و ( تِجَـار ) بكسر التاء و ( تُجَّار ) بالضم والتشديد.

حاشية: (١) كذا فى أكثر النسخ وليس هذا موضعه .
