بالكاف فقلتَ تِيــكَ وتِلْكَ وتَاكَ وتَلْكَ بفتح التـاء وهى لغــة رديئَةٌ وللتثنية تَانِكَ وتَانِّكَ بالتشـديد والجَمْـع أُولئكَ وأُولَاكَ وأُولَالِكَ فالكاف لمن تخاطبه فى التذكير والتأنيث والتثنية والجمع وماقبل الكاف لمن تُشِير إليه فى التذكير والتأنيث والتَّثْنِيَة والجمع فإن حَفِظت هذا الأَصلَ لم تُخْطِئْ فى شىء من مسـائله . وتدخل ها على تِيك وتَاكَ تقول هاتِيك هِنْدُ وهَاتَاكَ هِنْدُ ولا تدخل هَا على تِلكَ لأن اللاَمَ عِوض من ها التنبيه وتالِك لُغَةٌ فى تِلْك

* ت أ ت
رجُـل ( تَأْتَاءُ ) على فَعَلَال وفيه ( تَأْتَأَةٌ ) يتردَّد فى التاء إذا تَكَلَّم

→ تُؤَدة
فى و أ د

* ت أ م
( أَتْأَمَتِ ) المـرأةُ إذا وضَعَت ٱثنين فى بطنٍ فهى ( مُتْئِمٌ ) والوَلَدَانِ ( تَوْءَمَانِ ) يقال هذا ( تَوْءمُ ) هذا على فَوْعَل وهذِه ( تَوْءَمَة ) هذِه والجَمْع ( تَوَائِم ) مثل قَشْعَمٍ وقَشَاعِمَ و ( تُؤَامٌ ) أيضا بوَزْن حُطَام وإذا كان فى الآدميين لا يمتنع جَمْع مذكّره بالواو والنون كما يُجْمَع مؤَنَّثُه بالتاء

* ت ب ب
( التَّبَابُ ) بالفتح الخُسْران والهَلَاك تقول منه ( تَبِبْتَ ) يارجل تَتِبّ بالكسر ( تَبَابا ) . و ( تَبَّت ) يَدَاهُ و ( تَبًّا ) له منصوب على المصدر بإضمار فِعْل أى أَلْزَمَه اللهُ هلاَكا وخُسْرانا . و ( ٱسْتَتَبَّ ) الأَمْرُ تَهَيَّأَ وٱستقام

* ت ب ر
( التِّبْر ) ماكان من الذَّهَب غيرَ مضروب فاذا ضُرِب دَنَانِيرَ فهو عَيْنٌ ولا يُقَـال تِبْرٌ إلا للذَّهَب وبعضـهم يقوله للفِضّة أيضا . و ( التَّبَار ) بالفتح الهَلَاك و ( تَبَّره تَتْبِيــرا ) كَسَّره وأهلَكَه وهؤلاء ( مُتَبَّر ) ماهُمْ فيه أى مُكَسَّر مُهْلَك

* ت ب ع
( تَبِعَـه ) من باب طَرِب وسَلِم إذا مَشَى خَلْفَه أو مَرَّ به فمَضَى معه وكذا ( ٱتَّبعه ) وهو ٱفتعل و ( أَتْبَعه ) على أَفْعَل إذا كان قد سبقه فلَحِقه وأَتْبَـع غيره يقـال أَتْبَعْتُــه الشىءَ فَتَبِعه . وقال
